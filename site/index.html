Find the lists that should mention your project.

stargap searches high-star awesome lists, verifies that they have a matching topic section, and tells you where your project is still missing. Runs entirely in your browser.

No install. No signup. GitHub anonymous limits may apply; paste a read-only token below for larger scans.

Enter a repository to see its distribution gaps.

How it works

  1. 1Reads your topics, description and README.
  2. 2Searches high-star curated lists in your category.
  3. 3Requires a real matching section and checks for an existing entry.
  4. 4Ranks the remaining gaps by relevance, list quality and reach.

Precision over volume: a bare Tools heading is not a match.

Zero dependenciesThe CLI is plain ESM and Node 18+. The web app has no backend.
Paste-ready outputEach result includes a Markdown entry you can adapt for a PR.
Honest limitsHeuristics, not magic. False positives become regression tests.
